    ☁️ Google Sheets Sync

    Sync your links to a Google Sheet. This is fast, reliable, and lets you edit links directly in the spreadsheet.

    📋 Setup Instructions
    1. Create a Google Sheet and go to Extensions > Apps Script
    2. Paste the provided script code and save it.
    3. Click Deploy > New deployment > Web app
    4. Set "Execute as" to Me and "Who has access" to Anyone
    5. Copy the Web app URL and paste it below.
